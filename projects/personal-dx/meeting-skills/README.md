# コンテキストから議事録スキルを作る

機関紙連載「個人的DXのススメ」で紹介した、議事録作成用Agent Skillsの参考資料です。

## 収録資料

- `texts/specification.md` — 構築仕様書 Master Specification v1.0
- `code/validate_ids.py` — S-ID・M-IDの採番・整合性点検コード
- `code/validate_ids_README.md` — コードの使用方法
- `samples/public-sample-minutes.pdf` — 公開用ダミー議事録デザイン見本
- `texts/build-prompt.md` — Skills群の構築に使用したプロンプト

5つのSkills本体は、この版には含まれていません。

## 注意

本資料は記事の参考用です。利用環境に応じた調整が必要であり、そのままの動作を保証するものではありません。AIによる重要な処理結果は必ず人が確認してください。機密情報や個人情報を扱う場合は、所属組織の情報管理規則と各サービスの利用条件を確認してください。
